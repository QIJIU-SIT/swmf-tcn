# Third-party code

The only vendored third-party implementation is the necessary supervised PatchTST core from [yuqinie98/PatchTST](https://github.com/yuqinie98/PatchTST), used by the actual PatchTST-MV adapter. Four Python files are retained byte-for-byte from the local research copy: `models/PatchTST.py`, `layers/PatchTST_backbone.py`, `layers/PatchTST_layers.py`, and `layers/RevIN.py`, under `third_party/PatchTST/PatchTST_supervised/`.

PatchTST's [Apache-2.0 license](https://github.com/yuqinie98/PatchTST/blob/main/LICENSE) is included as `third_party/PatchTST/LICENSE`. No upstream NOTICE file was present in the inspected local copy. Retained source headers are unchanged. Other upstream model families, data loaders and experiment utilities are excluded. File hashes and the original/full versus extracted source-tree fingerprints are recorded in `third_party/PatchTST/PROVENANCE.json`. Trimming the source tree changes its provenance fingerprint, not these files' implementations. Newly trained release checkpoints bind the extracted fingerprint; historical checkpoint bundles are not distributed or promised to load unchanged.

`layers/RevIN.py` explicitly attributes code to [ts-kim/RevIN](https://github.com/ts-kim/RevIN) with minor modifications made upstream. Its [MIT License](https://github.com/ts-kim/RevIN/blob/master/License), copyright 2022 Electronics and Telecommunications Research Institute (ETRI), is separately retained as `third_party/PatchTST/REVIN_LICENSE`. This release makes no additional modifications to that file.

These licenses permit redistribution subject to their notices and terms. They do not license the authors' own files automatically. The author-owned code license remains to be selected by the rights holders before the candidate is published. NumPy, pandas, PyYAML, PyArrow and PyTorch are dependencies installed separately; their distributions and licenses are not bundled here. No FAITH, M2M, unrelated baseline source trees or model weights are redistributed.
